# API сервера расписания

Приложение умеет синхронизироваться с любым сервером, который отвечает так, как описано
здесь. Наш сервер — [server/](../server), адрес `https://dnui-schedule.hsryata.com`.
Поднять свой: тот же код в свой аккаунт Cloudflare (см. [server/README.md](../server/README.md))
или своя реализация этого контракта на чём угодно.

Всё только по HTTPS, ответы — JSON в UTF-8, чтение без авторизации.
Префикс `/v1` меняется, только если формат ломает старые приложения.

## `GET /v1/groups`

Группы, открытые для списка в онбординге. Скрытые сюда не попадают, к ним подключаются по коду.

```json
{ "groups": [ { "code": "k7m2qx", "title": "留软件25401 (俄财大), класс 1" } ] }
```

## `GET /v1/groups/{code}`

Всё расписание группы. `code` — `[a-z0-9]{1,32}`.

```json
{
  "code": "k7m2qx",
  "title": "留软件25401 (俄财大), класс 1",
  "rev": 42,
  "meta": { "title": "…", "week1_monday": "2026-08-31", "weeks": 16 },
  "slots": [ { "n": 1, "start": "08:00", "end": "09:40" } ],
  "lessons": [ {
    "id": "1-1-汉语口语1-1", "name": "汉语口语1", "name_ru": "Разговорный китайский 1",
    "weeks": [1, 8], "day": 1, "slot": 1, "start": "08:00", "end": "09:40",
    "teacher": "艾画宇", "room": "A6-413", "room_ru": "A6-413",
    "building": "A6", "building_ru": "корпус A6"
  } ],
  "shifts": { "2026-10-01": 0, "2026-09-27": 1 },
  "homework": [ { "lesson": "1-2-汉语1-1", "date": "2026-09-21", "text": "упр. 3–5", "until": "2026-10-01" } ],
  "changes": {
    "2026-10-08": { "4-3-金融大数据分析-1": null },
    "2026-10-15": { "1-1-汉语口语1-1": {
      "name": "体育", "name_ru": "Физкультура", "slot": 1, "start": "08:00", "end": "09:40",
      "teacher": "", "room": "体育馆", "room_ru": "спортзал", "building": "体育馆", "building_ru": "спортзал"
    } }
  }
}
```

- `meta`, `slots`, `lessons` — тот же формат, что выдаёт разбор xlsx в приложении
  (эталон — [fixtures/](../fixtures)).
- `lessons[].id` должен быть стабильным: к нему в приложении привязаны личные заметки
  и домашка. Пара сменила `id` — заметки к ней отвалятся.
- `day` — 1 = понедельник … 7 = воскресенье. В `shifts` 0 значит выходной, иначе — чьи пары идут в этот день.
- `homework[]`: `lesson` + `date` — пара и дата, где задали; `until` — до какой даты
  показывать на следующих парах по предмету, `null` — только на следующей.
- `changes`: правки на одну дату, в остальные недели пара идёт как обычно. `null` — пара отменена,
  объект — что идёт вместо неё: поля пары без `id`, `day` и `weeks` (они остаются от исходной).
  Замена живёт под `id` исходной пары, домашка и заметки этой даты привязаны к нему.
  Поле необязательное: старые приложения его не знают и покажут пару по расписанию.
- `rev` растёт при любой правке группы, переносов, правок на дату или домашки.

Кэширование: ответ несёт `ETag: "{rev}"` и `Cache-Control: no-cache`. Приложение шлёт
`If-None-Match` с последним `ETag`, если ничего не менялось — сервер отвечает `304` без тела.

## `GET /g/{code}` — ссылка-приглашение

HTML-страница группы: название, крупный код и кнопка
`raspisanie://connect?server={origin}&group={code}`, которую приложение ловит для любого
сервера. Необязательна: приложение подключается и по коду, и по ссылке, вставленной в поле.

## `GET /.well-known/assetlinks.json`

Для [App Links](https://developer.android.com/training/app-links): с ним Android открывает
`https://сервер/g/…` сразу в приложении. Работает только для домена, прописанного в манифесте
приложения при сборке, — у своего сервера без своей сборки APK не нужен.

## Запись: `/v1/admin/*`

Только для редакторов: путь закрыт Cloudflare Access, сервер дополнительно проверяет подпись
его токена (`Cf-Access-Jwt-Assertion`). Автор правки — email из токена. Запросы с чужим
`Origin` отклоняются (`403`). Ответ на любую правку — `{"rev": N}` с новой ревизией группы.

| Запрос | Тело | Что делает |
|---|---|---|
| `GET /v1/admin/me` | — | `{"email": …}` — кто вошёл |
| `GET /v1/admin/groups` | — | все группы, скрытые тоже: `code, title, listed, rev, updated_at, updated_by` |
| `POST /v1/admin/groups` | `{title, week1_monday, slots?, lessons?, listed?}` | новая группа, `201 {"code", "rev"}` |
| `PATCH /v1/admin/groups/{code}` | `{title?, week1_monday?, listed?}` | название, начало семестра, показ в списке |
| `DELETE /v1/admin/groups/{code}` | — | группа вместе с переносами, правками на дату и домашкой |
| `PUT /v1/admin/groups/{code}/lessons` | `{rev, slots, lessons}` | пары целиком; `rev` не текущий — `409 {"rev": текущий}` |
| `PUT /v1/admin/groups/{code}/homework/{lesson}/{date}` | `{text, until?}` | домашка на паре `{lesson}` (id, URL-кодированный) в дату `{date}` |
| `DELETE /v1/admin/groups/{code}/homework/{lesson}/{date}` | — | убрать домашку |
| `PUT /v1/admin/groups/{code}/changes/{lesson}/{date}` | `{lesson}` | пара `{lesson}` только в дату `{date}`: `null` — отменить, объект — что идёт вместо |
| `DELETE /v1/admin/groups/{code}/changes/{lesson}/{date}` | — | вернуть как по расписанию |
| `PUT /v1/admin/groups/{code}/shifts/{date}` | `{day}` | 0 — выходной, 1–7 — чьи пары идут |
| `DELETE /v1/admin/groups/{code}/shifts/{date}` | — | убрать перенос |

Неверные данные — `400 {"error":"bad_request","message":"…"}`, текст можно показывать как есть.
Домашка к паре, которой в группе нет, не принимается; домашка к паре, которую потом убрали
из расписания, остаётся в базе, но приложение её не покажет.

## Ошибки

`404 {"error":"not_found"}` — нет такой группы или пути, `405 {"error":"method_not_allowed"}` —
не GET вне `/v1/admin`, `401 {"error":"unauthorized"}` — запись без входа. CORS открыт (`Access-Control-Allow-Origin: *`): данные публичные.
